# Своя викторина

Викторина в стиле «Своей игры» для двух команд: табло для экрана-презентации и кнопки-пульты на телефонах.

- **Табло ведущего:** откройте сайт, нажмите «Пульты команд» и отправьте ссылки командам.
- **Пульт команды:** ссылка вида `?room=КОД&team=1` (или `team=2`), либо `?join` — ввести код вручную.
- **Вопросы:** 1100 штук в `questions.json` (11 категорий × 100, по 20 на каждую цену); 25 флагов лежат в `img/flags`, 35 фото подгружаются с Wikimedia Commons. Исходники в `data/*.txt`, формат `уровень|вопрос|ответ`; пересборка: `python3 data/build.py` из корня репозитория.
- **Связь пультов:** публичный MQTT-брокер `broker.emqx.io` по WebSocket. Другой брокер можно задать параметром `?broker=wss://...` (одинаковым у ведущего и у обоих телефонов).
